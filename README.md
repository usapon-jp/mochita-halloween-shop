# もちたの小さな雑貨とおやつのお店（ハロウィン箱庭）

Three.js だけで作った、もちた用のお店の箱庭（PV撮影用）。画像・3Dモデル不使用、すべてコードで生成。**もちた本体のモデルは含みません**（カウンター中央のピンクの座布団が置き場）。

- 操作: 下のボタン / 数字キー1〜4でカメラ切替、`T` おまかせ、`H` またはダブルタップでUI非表示/表示、`G` もちた置き場の目安。
- URLパラメータ: `?shot=counter|overview|window|closeup`、`?theme=pastel`（春・パステル配色）、`?hideui`、`?frame=16:9`、`?model=相対パス.glb&h=0.95`（GLBを置き場に配置）。
- ローカル起動: `node server.mjs` → http://127.0.0.1:4193/

## 既知の課題
- 実機スマホでの速度は端末次第（飾りが多い）。重い場合は全景を避ける。
