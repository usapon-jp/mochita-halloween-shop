# もちたの小さな雑貨とおやつのお店（ハロウィン箱庭）

Three.js だけで作った、もちた用のお店の箱庭。お店・小物・庭はすべてコードで生成（画像素材なし）。カウンターにもちた（軽量モデル）がいて、**タップするとその場所へ歩いてきます**。

## あそび方
- **タップ**: 画面をタップした場所まで、もちたが歩いてきて、止まって、こっちを向きます（障害物はよけて、カウンターはジャンプで乗り越えます）。
- **ドラッグ**で回す、**ピンチ**（PCはホイール）で拡大、**2本指**（PCは右ドラッグ）で平行移動。左上のお店の名前のタグをタップすると、エリア（カウンター・全景・窓辺・小物）を選べます。「おまかせ」で自動巡回。
- **もちたボタン**（右下の顔のアイコン）: **もちたモード**。画面の左側を触った所にスティックが出て、動かした向きにもちたが歩きます。右側のドラッグでカメラを回します。**ジャンプ**と**ダッシュ**のボタンも出ます（PC: 矢印/WASD、Space、Shift）。
- **カメラボタン**: いまの画面を写真に（スマホは共有、PCは保存）。画像の隅に小さくクレジットが入ります。
- **右上**: **枠のボタン**=画面だけを見る（UIを隠す。`H`キー。隠したあとは右上隅をタップで再表示）、**歯車ボタン**=あそびかた・歩くはやさ・クレジット。
- URL: `?shot=counter|overview|window|closeup` 開始カメラ、`?theme=pastel` 春のパステル配色、`?hideui` UI非表示で開始、`?noplay` 歩行をオフ、`?nsmooth=0` もちたの陰影なめらか化をオフ、`?studio` もちただけを無地背景で表示。
- ローカル起動: `node server.mjs` → http://127.0.0.1:4193/

## 既知の課題
- 飾りが多いため、端末によっては全景が重いことがあります（実機のスマホでの速度は未計測）。
- 小さな小物や茂みには当たり判定がなく、もちたは通り抜けます。
