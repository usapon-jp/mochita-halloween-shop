# もちたの小さな雑貨とおやつのお店（ハロウィン箱庭）

Three.js だけで作った、もちた用のお店の箱庭（PV撮影用）。お店・小物・庭はすべてコードで生成（画像素材なし）。カウンター中央の座布団に、軽量版のもちた（静止ポーズ）を置いています。

## 見方
- スマホ/PCのブラウザで開くだけ。下のボタンでカメラ（カウンター・全景・窓辺・小物）を切り替え、「おまかせ」で自動巡回。
- UIを隠す: ダブルタップ（PCは `H` キー）。もう一度で再表示。
- URL: `?shot=counter|overview|window|closeup` 開始カメラ、`?theme=pastel` 春のパステル配色、`?hideui` UI非表示で開始、`?nsmooth=0` もちたの陰影なめらか化をオフ、`?look=plain|felt` 質感の切替、`?studio` もちただけを無地背景で表示。
- ローカル起動: `node server.mjs` → http://127.0.0.1:4193/
